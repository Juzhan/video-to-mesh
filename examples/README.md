# Examples

`settings.json` shows optional overrides. Replace names with **exact input filenames** and remove entries for objects not in your input folder. Masses here are examples, not measurements.

Pass it as the third argument: `./run-videos.sh input output_me examples/settings.json`.

The curated [mug demonstration](mug/README.md) includes a metric OBJ and links to a silent capture GIF and rendered result. Full raw phone recordings, other personal captures and reconstruction caches are excluded. For synthetic capture generation, see [development](../docs/development.md).
