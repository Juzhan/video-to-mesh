# 拍摄与 A4 参照板

下载仓库中的 [单页 PDF](../calibration/a4-dense/reference-board.pdf)，用普通 A4 纸打印，选择 **100% / 实际大小**，关闭“适合页面”。量一次纸上的水平、垂直校验线并核对尺寸；不正确时调整打印设置。之后同一张纸可用于不同物体，不必给每件物体手工画尺寸。

把纸贴平，放在与物体相同的平面上。物体可以放在旁边、可以比纸大；不要覆盖全部定位码。建议每帧至少有 8 个清晰完整、在两个方向分散的码。视频中纸和物体都不移动、不翻面，只有相机移动。

1. 一件物品录一段原始 1080p / 30 fps 视频，通常 45–90 秒是合适的试拍起点。
2. 光线充足、均匀，缓慢绕行；加入低、中、高斜角，邻近画面保持重叠。
3. 尽量让完整物体留在画内，同时拍清细节。几帧局部出画可由其他视角弥补，但不能让某个部件始终缺少观测。
4. 使用同一镜头和焦段，避免数字变焦；不要经过聊天软件压缩。
5. 杯碗额外拍到内壁与内底；泵嘴、把手、机翼等应在多个角度清晰可见。

白色或木纹桌面都可以，但物体与背景要可区分。透明、强反光和缺少纹理的表面依然困难；参照板解决尺度与相机参考，不能补出物体没有拍清的细节。

快速档从整段视频的 48 个时间段挑清晰帧，并将深度重建长边缩到 640 像素；因此小物件在画面中占比太小时，细节会丢失。让物体占较多画面，同时保留足够分散的定位码。

PDF、SVG 和板定义应配套使用：默认 `calibration/a4-dense/board.json`。仓库中的其他板布局是可选旧配置，不要只换纸而不换定义。
