▧ 物体采集局域网直传
PHONE → COMPUTER → 3D

拍一件，传一件。

手机视频直接送到电脑，自动排队生成模型。
上传下一件时，电脑可以继续处理上一件。

连接电脑

手机连上电脑热点或同一个 Wi-Fi，输入电脑显示的配对码。

发送一个物体

01 / 采集

建议先把手机相机设为 1080p / 30 fps。物体和 A4 参照板保持不动，手机绕物体拍摄。若浏览器不能直接拍摄，可先录好再选择视频。

一次上传，本地测量尺寸、Meshy 生成外形。仅 Meshy 生成消耗 API 积分；默认不生成 smooth 版本。

正在上传0%

上传时请保持本页在前台、屏幕亮起。断线或暂停后，重新选择同一视频可以续传；电脑确认接收后即可关闭网页。

电脑处理队列

电脑逐件生成，不需要等待全部视频上传完。完成后可直接下载 OBJ 或整包。

还没有上传视频

视频只传到这台电脑。选择 Meshy 时，电脑会发送选出的物体图片用于生成。
